# 🌤️ Real-Time Weather Finder

A simple web app that fetches live weather data using the OpenWeather API.  
Users can search any city and instantly see temperature, humidity, wind speed, and conditions.

### 🔍 Features
- API calls using `fetch` + `async/await`
- Error handling for invalid cities
- Dynamic DOM updates
- Clean and responsive UI

### 🛠️ Tech Stack
- HTML  
- CSS  
- JavaScript  
- OpenWeather API
